# 토스쇼핑 쉐어링크 조사 (2026-07-28)

딜방에 쿠팡 링크와 토스쇼핑 링크가 섞여 올라오는 것이 확인되어,
토스쇼핑으로도 수익을 낼 수 있는지 공식 문서를 조사했다.

**조사 결과 한 줄 요약: 쉐어링크에는 공개 API가 없다.
링크 생성은 토스 앱/웹의 공유 UI 를 거쳐야만 한다.**

---

## 문서가 두 개로 나뉘어 있다

처음 지목된 `shopping-docs.toss.im/dev` 는 **제휴와 무관한 셀러용 API** 였다.

| 문서 | 대상 | 내용 |
|---|---|---|
| `shopping-docs.toss.im` | **셀러(판매자)** | 상품 등록, 주문 처리, 재고·배송 연동 |
| `sharelink-docs.toss.im` | **크리에이터(제휴)** | 쉐어링크 발급, 리포트, 정산 ← 우리가 원하는 쪽 |

셀러 API 에는 어필리에이트 링크 생성 기능이 없다. 상품을 파는 쪽의 API 다.

---

## 쉐어링크 링크 생성 방법 (공식 문서 기준)

```
토스쇼핑에서 상품 상세 페이지로 이동
  → 상단 공유 아이콘 탭
  → '쉐어링크 공유하기' 선택
  → 링크 발급
```

문서에 **없는** 것:

- 상품 URL 을 붙여넣어 링크를 만드는 방식
- 개발자용 API / 엔드포인트 / 인증 방식
- 프로그래매틱(자동) 링크 생성 수단

`llms.txt` 문서 인덱스 전체(11개 항목: 링크 만들기, 리포트, 실적 대시보드,
수익금 계산, 정산 내역, 정산액 지급, 세금계산서, 공지사항, 운영 정책, FAQ)에
개발/연동/API 항목이 존재하지 않는다.

### ⚠️ 일반 공유 링크는 수익이 0 이다

> "일반 공유 메뉴(`공유하기`)로 만든 링크는 수익이 발생하지 않아요."

반드시 `쉐어링크 공유하기` 로 만든 링크여야 한다.
**CLAUDE.md 제약 4번(손으로 조립한 링크는 트래킹이 안 붙는다)과 같은 함정이다.**
토스에도 그대로 적용된다.

---

## 운영 정책에서 확인한 것

### 대가성 고지 — 쿠팡과 문구도 위치 규정도 다르다

> "이 포스팅은 토스쇼핑 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

- **모든 게시물에 빠짐없이** 포함
- **게시물 제목이나 첫 부분에** 명확히 노출

쿠팡 고지는 `threads_post.py` 에서 본문 **끝**에 붙이고 있다.
토스는 **첫 부분** 을 요구하므로, 토스 링크를 발행하려면 문구 배치 규칙이
링크 종류에 따라 달라져야 한다. 두 고지 문구를 혼용해서도 안 된다.

### 자동화 관련 조항

> "무효 클릭, 자동 실행, 과도하게 클릭을 유도하는 등 사용자의 의도에 반하는
> 방식은 모두 금지"

문맥상 **클릭 조작(클릭 어뷰징) 금지**로 읽힌다. 링크를 자동으로 생성하는
행위를 명시적으로 금지한 조항은 아니다. 다만 매크로·크롤링에 대한 별도
허용 조항도 없다. 회색지대다.

위반 시 **수익금 지급 중단 또는 계약 해지**.

### 가입 조건과 수수료 — 공식 FAQ 확인

> "링크를 공유할 수 있는 분이라면 누구나 가능해요.
>  홈페이지, 블로그, SNS 등 자신이 운영하는 채널에서 바로 시작할 수 있어요."

| 항목 | 값 | 출처 |
|---|---|---|
| 가입 자격 | 채널만 있으면 누구나. 사업자/개인 모두 | FAQ |
| 수수료 | **링크 접속 후 24시간 내 구매액의 10%** | FAQ |
| 월 최대 수익금 | 3,000만 원 | FAQ |
| 지급일 | 다음 달 25일 | FAQ |
| 고지 의무 | "모든 게시물에는 경제적 이해관계를 꼭 표시" | FAQ |

계약 이행 과정에서 필요서류 제출과 세금계산서 역발행 승인이 요구된다.

### 쿠팡과 비교하면 진입 장벽이 훨씬 낮다

| | 쿠팡 파트너스 | 토스 쉐어링크 |
|---|---|---|
| 가입 | 승인 필요 | 채널만 있으면 누구나 |
| 수수료 | 3~5% | **10%** (24시간 창) |
| 링크 생성 API | 최종승인 + 누적 판매 15만 원 필요 | 공개 API 없음 |

**수수료가 2~3배이고 가입 장벽이 사실상 없다.**
CLAUDE.md 의 Phase 계획은 쿠팡 API 승인을 최종 목표로 두고 있는데,
토스 쪽이 더 빨리 수익이 날 가능성이 있다. 단, 링크 생성 자동화 수단이
확인되어야 한다는 전제가 붙는다.

## 이 프로젝트에 주는 의미

이 방은 **상품 발굴 소스**다. 이미 최저가로 걸러진 상품 리스트를 얻는 곳이지
링크를 얻는 곳이 아니다. 방에 올라온 링크는 방장의 것이므로, 상품만 알아내고
링크는 내 것으로 새로 만든다. 쿠팡에서 이미 그렇게 설계되어 있다.

```
방의 단축링크 → 실제 상품 URL + 상품ID 확정 → 내 링크 생성 → 발행
```

### 단축링크 해석 — 실측 검증 완료 (2026-07-28)

`toss.im/_m/...` 는 리다이렉트 1회로 풀린다.

```
https://toss.im/_m/9X1XXhQf
  ↓
https://toss.shopping/t/524516537?k=99af7d09-fc31-4a94-99f1-e6a567ddbce5&referrer=affiliate
```

| 조각 | 의미 |
|---|---|
| `toss.shopping/t/(\d+)` | **상품 ID.** 쿠팡의 `/vp/products/(\d+)` 에 대응한다 |
| `k=<uuid>` | **방장의 트래킹 키.** 반드시 버린다 |
| `referrer=affiliate` | 제휴 링크임을 나타냄. 버린다 |

파라미터를 제거한 `https://toss.shopping/t/524516537` 로 접속하면 정상
동작하고(HTTP 200), 토스가 스스로 이 주소를 정식 URL 로 선언한다.

```html
<meta property="og:url"   content="https://toss.shopping/t/524516537">
<meta property="og:title" content="이장네푸드 전통압착 통들기름 100%, 350ml, 4개 | 토스쇼핑">
<meta property="og:description" content="... 들기름 1위. 리뷰 185개 · 평점 4.7점">
```

**상품명을 `og:title` 에서 그대로 얻을 수 있다.** 채팅 메시지를 추측 파싱하는
`guess_title()` 보다 정확하다. 토스 딜은 이 경로를 쓰는 게 낫다.
(`| 토스쇼핑` 접미사는 떼어낼 것.)

### 남은 병목은 링크 생성 한 곳뿐이다

| 단계 | 토스 | 근거 |
|---|---|---|
| 딜방에서 토스 링크 추출 | ✅ | 정규식 추가만 하면 됨 |
| 단축링크 → 상품 URL + 상품ID | ✅ **검증됨** | 위 실측 |
| 상품명·가격 확보 | ✅ **검증됨** | `og:title` / `og:description` |
| **내 쉐어링크 생성** | 🔴 **미해결** | 공개 API 없음 |
| Threads 발행 | ✅ | 단 고지를 첫 부분에 둬야 함 |

문서상 링크 생성 절차가 "상품 상세 페이지 → 공유 아이콘 → 쉐어링크 공유하기"
인데, **이제 그 상품 상세 페이지 URL 을 프로그램으로 만들 수 있다.**
따라서 `partners_link.py` 와 같은 방식(로그인 세션을 가진 브라우저로 해당
상품 페이지를 열고 공유 버튼을 누르는 것)이 성립할 가능성이 높다.
확인이 필요한 것은 그 페이지에서 공유 UI 가 실제로 노출되는지 하나다.

## 다음에 확인할 것 (코드로 알 수 없음 — 소유자 확인 필요)

가장 중요한 하나: **`https://toss.shopping/t/<상품ID>` 를 로그인한 PC 브라우저로
열었을 때 '쉐어링크 공유하기' 가 보이는가?**

- 보인다 → `partners_link.py` 와 같은 방식으로 자동화 가능. 상품 URL 은 이미
  프로그램으로 만들 수 있으므로 남은 건 버튼 클릭뿐이다.
- 안 보이고 토스 **앱 전용**이다 → PC 무인 운영으로는 불가능하다.
  토스는 수동으로 두고 쿠팡만 자동화하는 편이 낫다.

문서에 PC 웹 지원 여부가 명시되어 있지 않아 실제로 확인해야 한다.
